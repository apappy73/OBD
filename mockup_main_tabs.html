Notes on this mockup

  • Faithful to the current layouts: shared top bar (title + Connect/Disconnect tonal button + status line), fragment area, and the 3-item bottom nav. Values are illustrative, not real readings.
  • Tab 1 — PID spinner + Record switch, big value in colorPrimary, MPAndroidChart line chart, then a 2-column grid of PID cards.
  • Tab 2 — exactly the button set now in the DTC tab: Read stored / Read pending, Freeze frame / Monitor tests, then the outlined Clear. Code list uses the item_dtc style.
  • Tab 3 — fixed vehicle card, "Read from vehicle" + Refresh, then key/value rows. The last two rows (ECU hardware number, Calibration ID) are the just-added Mode 09 fields, shown as two ECUs joined with •.
  • Colour: the theme now overrides colorPrimaryContainer / colorSecondaryContainer (light #FFDADB, dark #93000F) so tonal buttons and the nav active pill use a Soul Red tint instead of Material's baseline. Shown here with the light-scheme tint.
  • Dark mode: a values-night/colors.xml supplies dark-scheme variants. Note that colorPrimary itself is still the mid-dark #A6192E in dark mode — fine on a light surface, but low-contrast for primary-coloured text (e.g. the big value on Tab 1) on a dark surface. Turning that into a light tone for night is a separate decision.
